# AffStore — V4 dynamique

- `index.html` : structure (les listes de produits sont générées par JS)
- `css/style.css` : styles + animations
- `js/main.js` : produits (tableau PRODUCTS), recherche avec suggestions, panier (sauvegardé dans localStorage), favoris, tri, effets
- `assets/images/` : illustrations SVG. Pour mettre de vraies photos, remplace le fichier ou change `img` dans PRODUCTS (et la fonction `src()`).

Pour ajouter un produit : ajoute un objet dans PRODUCTS (js/main.js) + son image.
